# Alert and deployment gate
- [ ] Alert condition corresponds to intended executed event
- [ ] Frequency and duplicate behavior are defined
- [ ] Payload has strategy/version/symbol/timeframe/event identifiers
- [ ] Receiver is idempotent or deduplicates
- [ ] Secrets are absent from repository and prompt history
- [ ] Stale/reordered/missing alert behavior is defined
- [ ] Paper test completed before live use
- [ ] Human approval recorded
