# Robustness Study Prompt

Use `robustness-optimizer`. Given the baseline script and exported results, design a robustness study rather than searching for the highest net profit.

Include:
- parameter sensitivity grid
- anchored or rolling walk-forward windows
- neighboring symbols/timeframes
- cost and slippage stress tests
- delayed-entry and degraded-fill tests
- regime segmentation
- Monte Carlo resampling concept where data permits
- rejection thresholds
- a decision table: retain, simplify, revise, or reject
