# Research Examples

Worked examples of completed research artifacts, kept as references for how to fill the templates
in [`../templates/`](../templates/). Examples illustrate **form and rigor**, not validated
strategies.

## Status

No examples exist yet. The first example will be produced by the recommended next task: a single
controlled research project exercising observation → research question → hypothesis →
specification, without Pine implementation or optimization (see
[`../../NEXT_ACTIONS.md`](../../NEXT_ACTIONS.md)).

## Rules for examples

- Clearly label every example as an **example**, not a real registered project, unless it is a
  real closed project intentionally showcased.
- Examples must obey the same integrity rules: no fabricated evidence, no profitability claims,
  and any illustrative numbers marked as illustrative.
- Prefer linking a real closed project (with its research ID) over inventing content.
