Promoted lessons distilled from closed research projects — including, and especially, failed and
negative results. Lessons are the mechanism by which project-specific evidence becomes reusable
institutional memory, per
[`../../docs/research/KNOWLEDGE_MANAGEMENT.md`](../../docs/research/KNOWLEDGE_MANAGEMENT.md).

## How lessons are created

1. At closeout ([`../../research/templates/RESEARCH_CLOSEOUT.md`](../../research/templates/RESEARCH_CLOSEOUT.md)),
   the owner identifies reusable lessons.
2. Copy [`LESSON_TEMPLATE.md`](LESSON_TEMPLATE.md) to `LES-###-<slug>.md` in this folder.
3. Cite the source project(s) (research ID) and the specific evidence records.
4. A second-party review promotes the lesson from `draft` to `reviewed`.

## Naming

- File: `LES-###-<slug>.md` (zero-padded sequential number).
- Each lesson carries the standard metadata block and links its evidence.

## Contradictions

If later evidence contradicts a lesson, mark it (`superseded` / `Stale:`) and write a successor;
never silently rewrite. See
[`../../docs/research/KNOWLEDGE_MANAGEMENT.md`](../../docs/research/KNOWLEDGE_MANAGEMENT.md).
